## 七、子女端知情通知

老人的下列操作**不会**被拦下，但会实时推送到子女端（WebSocket 实时提醒 + 子女端「实时通知」列表留痕）。
设计原则：**不打断老人，但不让子女不知情**。风控能拦的由规则引擎拦，拦不了的信息同步给家属。

| 触发动作 | 子女端收到的通知 | 是否需要子女操作 |
|---|---|---|
| 申购理财产品 | 老人申购了理财产品 ·「安心存三个月」10,000.00 元 | 不需要，仅知情 |
| 赎回理财 | 老人赎回了理财 | 不需要，仅知情 |
| 高风险理财申购 | 走 L2 授权票据，需要子女放行 | **需要授权** |
| 卡片挂失 | 老人挂失了银行卡 | 不需要，仅知情 |
| 提交办卡申请 | 老人提交了办卡申请 | 不需要，仅知情 |
| 守护日历动作链执行 | 守护日历动作链已执行 | 不需要，仅知情 |
| 设置定期转账 | 老人设置了定期转账 | 不需要，仅知情 |
| 大额转账 | 走 L2 授权票据，需要子女放行 | **需要授权** |
| 风控拦截 | 一笔操作被风控拦下 + 完整拦截原因 | 不需要，需关注 |
| 紧急止付 | 老人触发了紧急止付 + 冻结范围与 96110 引导 | 不需要，需立即关注 |

老人端会在操作结果里明确看到「这件事已经同步通知张伟了」，不存在"背着子女办业务"的情况。
